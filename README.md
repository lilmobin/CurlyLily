# for Curly Lily

A single-screen cinematic music experience.
Intro -> title reveal -> loading + lily bloom -> flower dissolves into particles -> final player screen.

## 1. Put your files here (replace the placeholders)

| File                | What it is                                        |
|---------------------|---------------------------------------------------|
| `assets/title.png`  | Your transparent PNG of "for Curly Lily"          |
| `assets/music.mp3`  | Your song                                         |
| `assets/cover.jpg`  | Square album artwork (optional)                   |

Keep the same file names, or change the paths in `js/config.js`.
The title PNG is used exactly as-is - no text is generated by the site.

## 2. Change the song name, artist, and timings

Open `js/config.js`:
- `song.title` / `song.artist` - text shown in the player
- `timing.loading` - how long the loading bar + flower bloom takes
- `timing.flowerDissolve` - how long the flower takes to become particles
- `particles.fall` - amount of drifting particles on the final screen

## 3. Run it

ES modules do not work from `file://`, so serve the folder:

    python3 -m http.server 8000
    # then open http://localhost:8000

Or upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, cPanel).

## Handy extras
- `?t=6.5` in the URL jumps to that second of the timeline (useful for tuning).
- Press `Esc` during the intro to skip straight to the final screen.
- Autoplay: the site tries to play the song on the final screen. If the browser
  blocks it, the player stays paused and the first tap on Play (or anywhere) starts it.
- `prefers-reduced-motion` visitors go straight to the calm final screen.
